#### Vanilla JavaScript quiz eLearning which modifies an existing question bank by randomizing question data, dynamically choosing the number of questions, allows the user to cycle through questions with a previous and next button, counting a total score for the user based on quiz submission, randomizing the question options order, and enhancing the user experience with a minimalistic & clean ui design

#### Instructions: 
#### 1. npm i
#### 2. npm run build
#### 3. npm run live
